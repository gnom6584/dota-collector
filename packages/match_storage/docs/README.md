# Match Storage

Базовый контракт целевого хранилища обогащенных матчей Dota 2.

## Архитектура

```
packages/match_storage/
├── docs/
│   └── README.md        # Документация пакета
├── storage.py           # Абстрактный контракт Storage
└── __init__.py          # Публичный API пакета
```

---

## Архитектурные принципы

1. **Изоляция персистентности:**
   - Высокоуровневые конвейеры взаимодействуют с хранилищем исключительно через абстрактный интерфейс `Storage`.
   - Конкретные адаптеры баз данных (`match_storage_sqlite` и др.) реализуют низкоуровневые операции записи и контроля дискового пространства.
2. **Поддержка Backpressure:**
   - Метод `get_free_space() -> int` возвращает количество матчей, которое хранилище готово принять.
   - Метод `insert_many(matches) -> bool` гарантирует подтверждение записи пачки.
