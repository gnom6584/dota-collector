# Панель управления и веб-интерфейс администратора

## Обзор

Модуль `apps.admin` предоставляет веб-интерфейс и REST API для мониторинга в реальном времени, сбора телеметрии и динамической оркестрации конвейера сбора матчей Dota 2 (`public_match_collector`, `match_enricher` и `match_storage_writer`).

## Архитектура

Приложение панели управления взаимодействует с контуром данных исключительно через фасад `ControlPlane` и контейнер зависимостей `ApplicationContainer`, не имея прямых зависимостей от низкоуровневых SQL-запросов:

```
┌────────────────────────────────────────────────────────┐
│             Веб-интерфейс администратора (SPA)         │
└───────────────────────────┬────────────────────────────┘
                            │ HTTP / JSON
┌───────────────────────────▼────────────────────────────┐
│                  FastAPI REST Router                   │
│         (/api/stats, /api/workers, /api/configs)       │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│                      ControlPlane                      │
├─────────────┬─────────────────┬─────────────┬──────────┤
│   Backend   │ PipelineControl │   Storage   │  Quotas  │
└─────────────┴─────────────────┴─────────────┴──────────┘
```

## Функциональные возможности

1. **Телеметрия конвейера:**
   - Мониторинг размера очереди созревания и динамическое управление емкостью (`queue_max_size`).
   - Мониторинг и изменение задержки созревания на лету (`maturation_delay_seconds`).
   - Контроль количества сохраненных матчей и предельного объема хранилища (`storage_max_matches`).

2. **Оркестрация процессов воркеров:**
   - Фиксация реального статуса (`RUNNING`, `IDLE`, `WAITING`, `DISABLED`, `ERROR`), PID и времени обновления для всех трех воркеров (`public_match_collector`, `match_enricher`, `match_storage_writer`).
   - Динамическое включение и отключение воркеров без перезапуска процессов (`enable`, `disable`).
   - Просмотр и сброс зарегистрированных аварийных ошибок (`clear-error`).
   - Мониторинг расхода и управление суточными лимитами API-квот (OpenDota, Stratz).

3. **Динамическая конфигурация рантайма:**
   - `public_match_collector`: фильтры рангов, длительности, игровых режимов, кластеров, интервалы cooldown, задержки ретраев квот и rate limit.
   - `match_enricher`: размер пачки (batch size), задержка cooldown, время ожидания idle, задержки квот и rate limit.
   - `match_storage_writer`: задержка cooldown при записи транзакции, пауза idle, задержка при ошибках сохранения.
   - Конфигурации персистируются в таблицу `worker_configs` SQLite и применяются воркерами на следующем цикле выполнения.

4. **Инспектор сохраненных матчей:**
   - Таблица последних обогащенных матчей из целевой базы данных SQLite.
   - Постраничная навигация и фильтрация по `match_id`.
   - Модальное окно для детального просмотра полного исходного JSON-пейлоуда матча.

## Эндпоинты REST API

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/` или `/admin` | Одностраничное веб-приложение панели управления (Cyberpunk dark theme) |
| `GET` | `/api/stats` | Агрегированный снимок телеметрии системы (`SystemStats`) |
| `POST` | `/api/quotas/{name}/reset` | Сброс израсходованных единиц суточной квоты в 0 |
| `POST` | `/api/quotas/{name}/limit` | Динамическое обновление максимального суточного лимита квоты |
| `POST` | `/api/pipeline/queue/limit` | Динамическое изменение максимальной емкости очереди созревания |
| `POST` | `/api/pipeline/maturation-time` | Динамическое изменение времени созревания матчей (в минутах или секундах) |
| `GET` | `/api/configs/pipeline` | Получение текущего времени созревания (минуты/секунды) и емкости очереди |
| `POST` | `/api/storage/limit` | Динамическое обновление максимальной вместимости целевого хранилища |
| `POST` | `/api/workers/{name}/enable` | Активация воркера в координационном бэкенде |
| `POST` | `/api/workers/{name}/disable` | Деактивация воркера в координационном бэкенде |
| `POST` | `/api/workers/{name}/clear-error` | Сброс зафиксированной ошибки воркера |
| `GET` | `/api/configs/public-collector` | Чтение актуальной конфигурации сборщика публичных матчей |
| `POST` | `/api/configs/public-collector` | Сохранение конфигурации сборщика публичных матчей |
| `GET` | `/api/configs/enricher` | Чтение актуальной конфигурации обогатителя матчей |
| `POST` | `/api/configs/enricher` | Сохранение конфигурации обогатителя матчей |
| `GET` | `/api/configs/storage-writer` | Чтение актуальной конфигурации воркера сохранения |
| `POST` | `/api/configs/storage-writer` | Сохранение конфигурации воркера сохранения |
| `GET` | `/api/matches/recent` | Список последних сохраненных матчей с метаданными и пагинацией |
| `GET` | `/api/matches/{match_id}` | Полный JSON-документ обогащенного матча из хранилища |

## Запуск панели управления

```bash
python -m apps.admin
```

Веб-панель доступна в браузере по адресу: `http://127.0.0.1:8000/`.
